Embed Demo

把竖琴专区嵌进你自己的页面

下面这块就是被嵌入的内容：变调台、竖琴视频、AI 生成竖琴曲、曲谱区。 外层是你网站的页头，内层是 ?embed=1 模式的应用，两边互不影响。

↑ 这里是一整个 iframe，滚动是独立的，不会带动外层页面。

复制这段贴到你网站的「自定义 HTML」里 
<iframe
  src="https://你的域名/?embed=1"
  title="星声竖琴专区"
  style="width:100%;height:900px;border:0;border-radius:16px;overflow:hidden"
  loading="lazy"
  allow="autoplay; encrypted-media; picture-in-picture"
  referrerpolicy="no-referrer-when-downgrade">
</iframe>
为什么这里能跑、你网站里不能直接跑： 变调要 ffmpeg、生成竖琴曲要 numpy，都是后端算的。所以这个 iframe 的 src 必须指向一台能跑 Python 的机器（本机演示就是 127.0.0.1:8765， 上线时要换成你部署好的域名）。

演示地址：http://127.0.0.1:8765/embed-demo.html
